This project tackles the problem of predicting used-car purchase prices from the information available at registration time, with the aim of enabling faster and more consistent preliminary valuations. Using the provided 2020 dataset (≈76k training rows and ≈33k test rows), we first performed exploratory analysis to understand data quality issues such as missing values, inconsistent formatting, skewed distributions, and influential outliers.

We then designed a modular end-to-end regression pipeline with a strong focus on reproducibility and leakage prevention: all preprocessing transformations are fitted only on training data and, during validation, strictly within each cross-validation fold. The pipeline includes robust imputation (median for numeric fields and “Unknown” for categorical), normalization of high-cardinality text fields (e.g., brand/model) through custom matching, unit and type corrections, and feature engineering (notably vehicle age). To address heavy skew, we applied log transforms to variables such as mileage and price, and handled extreme values through IQR-based clipping. Categorical variables were encoded using one-hot encoding for low-cardinality fields and target/mean encoding for high-cardinality ones, balancing expressiveness and dimensionality.

Multiple regression algorithms were benchmarked under a consistent cross-validation strategy, and the best candidate was optimized via hyperparameter tuning. The final model (a tuned Random Forest regressor) achieved strong predictive performance, explaining about 91% of price variance (R² = 0.9079) with practical error levels (MAE ≈ £1,598; RMSE ≈ £3,000; median absolute error < £1,000). Finally, an ablation study was included to quantify which features and pipeline elements most influence performance, supporting clearer interpretation and more defensible conclusions.
